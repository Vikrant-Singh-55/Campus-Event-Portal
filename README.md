The Campus Event Management & Registration Portal is a web-based application designed to streamline the organization and student registration process for university events, workshops, seminars, and fests. Built using HTML5, Bootstrap 5, and JavaScript, the system provides a clean, responsive user interface for both students and event organizers.   Students can browse upcoming campus events, filter by category or venue, check live seat availability, and instantly reserve a seat. Upon registration, the platform automatically updates seat counts to prevent over-booking and generates a downloadable/printable registration pass. Additionally, an event creation module enables organizers to add new events dynamically, with all application state securely persisted across browser sessions using local storage
